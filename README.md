# 🛡️ VPN Configuration & Privacy Verification

## 📌 Overview

This project demonstrates practical VPN configuration and privacy verification using a desktop VPN client. It covers establishing a VPN connection, verifying public IP address changes, reviewing secure connectivity, and understanding VPN privacy features and limitations.

## 🎯 Objectives

* Configure and establish a VPN connection
* Verify changes to the public IP address
* Understand VPN protocols and encryption
* Review VPN privacy features and limitations
* Verify connectivity before, during, and after a VPN session
* Perform a basic browser security check

## 🔐 VPN Configuration

* **VPN Service:** ProtonVPN
* **Plan:** Free Tier
* **Protocol:** WireGuard (UDP)
* **Server:** Netherlands

## 🔧 Steps Performed

1. Selected ProtonVPN Free Tier and created an account.
2. Downloaded and installed the ProtonVPN desktop client.
3. Connected to a Netherlands VPN server.
4. Verified that the public IP address changed after establishing the VPN connection.
5. Browsed multiple websites to verify connectivity while connected to the VPN.
6. Disconnected the VPN and confirmed that the original network connection was restored.
7. Reviewed VPN encryption, privacy features, and limitations.
8. Reviewed installed browser extensions and removed unused or unnecessary extensions as a security precaution.

## 🔐 VPN Encryption & Privacy

### Protocol

**WireGuard (UDP)** was used for the VPN connection. It is a modern VPN protocol designed for secure and efficient communication.

### Encryption

The VPN connection provides encrypted communication between the device and the VPN server.

### Privacy Features

The VPN service used during this project provides features such as:

* Kill Switch
* NetShield for ad and malware blocking
* Split tunneling
* VPN server selection

## ✅ Benefits of VPNs

* Helps hide the device's public IP address from websites and online services
* Encrypts network traffic between the device and the VPN server
* Provides additional protection when using untrusted or public networks
* Can help access services available through different network locations
* Provides an additional layer of online privacy

## ⚠️ Limitations of VPNs

* Free VPN plans may provide fewer server choices or lower performance during congestion
* VPNs do not provide complete anonymity
* Websites can still use cookies, browser fingerprinting, and other tracking techniques
* Some online services restrict or block VPN connections
* Users must consider the privacy practices and trustworthiness of their VPN provider

* Browser security warnings and permissions were considered during the review

## 📚 Key Learnings

* A VPN can provide an additional layer of privacy and security for network traffic.
* Public IP address changes can be used to verify that a VPN connection is active.
* VPN protocols have different technical characteristics and security designs.
* A VPN does not guarantee complete anonymity.
* Browser security should be considered alongside network security.
* Understanding privacy policies and VPN limitations is important when selecting a VPN service.
